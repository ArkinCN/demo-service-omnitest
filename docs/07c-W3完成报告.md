## 五、未完成项与偏离，逐条说明

1. **「节点点击即放大」改成了「点击选中 / 双击或点放大按钮展开」。** 单击直接开浮层会和拖动节点这个基本操作打架——按下鼠标就算一次 click。现在：单击选中（描边高亮 + 写进 `canvasSelected`），双击开放大态，卡头右上角的放大按钮也开。这是有意偏离，不是漏做。

2. **缩放条放在左下角，与参考页不一致。** 任务卡第 4 条写的是「左下角百分比加复位按钮，位置与参考页一致」，但 `/mnt/f/Main/File/2_Projects/峰岹/峰岹agent/09-实验室demo线/20260919-通用Agent测试系统v2.0/_调研/ref-客户Copilot页面-用户提供-20260919.png` 上那排「− / 100% / + / 复位」实际在画布**右下角**。两句话打架，我按重复出现两次的文字口径落在左下角，顺带把右下角让给缩略导航图，免得两个控件叠在一角。要改成右下角是一行 CSS 的事，请编排者拍板。

3. **「落点之外放手取消」靠的是浏览器默认行为，没有专门写取消逻辑。** `drop` 事件只在画板容器内触发，松手在容器之外浏览器不会派发 `drop`，等于取消。行为是对的，但没有额外的取消动画或提示。

4. **边不能由人手画。** `nodesConnectable={false}`，连接点全部隐藏。规格只要求边表达两种语义、不参与计算，没要求人工连线；开放连线会让用户造出与物理接线矛盾的图，本轮先不开。

5. **`localStorage` 只存节点位置与新增节点，不存边。** 人拖进来的新节点没有边（本来也没地方来），版式复位按钮（缩放条上的「复位」）会一并清掉存的版式、回到场景包默认版式。

6. **场景包没有下发默认版式，默认版式写在代码里。** `/home/zzz/agent-test-web/src/features/canvas/model.ts` 的 `SEEDS` 是五条流程的初始节点与坐标。《第三轮需求变更方案 v0.1》第 2.4 节说「场景包下发一份默认版式作为初始值」——那要在 `scene.json` 里加一个 `canvas_layout` 段，而我的可改范围里 `scene.json` 只许加 `default_view` 一个字段，所以这一条本轮没做。

7. **一次并行期的观察，供编排者知悉：** 跑 `npx tsc -b` 中途撞到过一次 `src/features/copilot/context.ts(1,23): error TS6196: 'ModuleId' is declared but never used`，那是 W5 当时正在写的文件，几分钟后自行消失。最终三条验收命令都是在干净状态下跑过的。同样地，`npm run lint` 一度因为仓库根下出现 W5 的构建产物目录 `dist-w5/` 而涨到几百条 warning，现在那个目录已不在，整仓 lint 回到 22 条。
