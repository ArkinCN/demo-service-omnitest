## 2. 用户是谁、口味是什么

用户的全局硬性规则写在 `/home/zzz/.claude/CLAUDE.md`，共 R1 到 R11 十一条，接手模型必须遵守。要点摘录如下，原文以该文件为准。

| 规则 | 一句话要点 |
| --- | --- |
| R1 产出系统化 | 列举必须先分类后展开；同一列表内抽象层级对齐；一句话里顿号串联同类项不超过五个；能无限延长的列表判为偷懒 |
| R2 模型路由 | 用别名不写死版本。常规执行→`sonnet`，复杂任务→`opus`，超长程→`fable`，语言风格敏感的写作→`prose-46` agent（锁 Opus 4.6）。下限锁死 sonnet，任何任务不得降到 haiku。子 agent 的 prompt 一律要求报告搜索范围 |
| R3 禁 AI 腔之括号举例 | 不要写「多种算法（甲、乙、丙）」，举例要单独成句或用列表 |

### 7.7 三条最容易踩的硬约束

安装 DSH 插件时，顶层依赖只能有 `@deepseek-ai/dsh@0.1.5-rc.2` 一个，精确版本不带插入符或波浪号；严禁在顶层单独安装任何 DSH 子插件包，它们已内嵌在主包里，重复安装会提升出第二份更老的作用域包副本，两份互不识别，症状是网页端建会话失败、无头模式每次工具调用报读不到属性。出处 `04-同事实施任务详单-v2.0.md` 第 244 与 254 行。

安全 Hook 必须走 Claude Code 方言的桥，不能走 Codex 方言的桥。Codex 桥会把工具参数压扁成只剩命令字符串，阻断脚本看不到电流限值字段；Claude Code 桥原样传参，是唯一真正生效的阻断路径。两座桥可以都挂着，Codex 那座只做非阻断探针留证。

判据表达式里按位运算与比较运算不得出现在同一括号层。JavaScript 里按位与的优先级低于比较运算符，同层会静默算错，自检脚本的 C10 项专查这个。

按用户的编排者模式，执行工作一律派子 agent。三类常用 prompt 骨架如下，`model` 按 R2 选：常规执行 `sonnet`，复杂任务 `opus`。

### A.1 只读调研

```
只读任务（可运行 ls/cat/grep 等只读命令），不要修改任何文件，不要写报告文件。
结论直接作为最终消息返回。所有路径用绝对路径。

调查目标：<逐条列出，每条说清要什么>

报告你的搜索范围：跑了哪些命令、读了哪些文件、哪些路径不存在或读不到。
找不到就明确说找不到，不要编造。涉及数值的一律给出处。
```

调研与找全类任务再加一句：穷举式覆盖，禁止提前收敛，零命中也要逐条列出来当结论。常规执行类任务不要加这句。

## 附录 B. 写作规范摘要

本项目所有文档产出按下面六条自检，完整规则见 `/home/zzz/.claude/CLAUDE.md`。

| 条 | 自检问题 |
| --- | --- |
| 先分类后展开 | 这个列表有没有分类骨架？并列项是不是同一抽象层级？一句话里顿号串联的同类项超过五个没有？ |

| 反 AI 腔 | 有没有用括号塞举例？段首有没有「其实」「简而言之」？有没有「毫无疑问」这类无证据强调？有没有「按用户要求」一类元叙事？ |
