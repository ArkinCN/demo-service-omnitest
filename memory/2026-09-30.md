## ✅ 一键自动化测试流程（2026-09-30，已实现 + 浏览器验收 10/10）

用户诉求：两种入口（AI 输入「启动自动化测试流程」/ 首页「智能测试」按钮）启动同一套全自动测试（确认参数→阶段推进→跳页→播报→生成下载报告），**真机自动启动要真做，不做 TODO**。

### 架构（分层 + 依赖倒置 + 单向数据流，硬约束）
- **唯一新 ts**：`web/src/features/automation/automationOrchestrator.ts` —— 纯逻辑编排器（类型/9事件协议/轻量事件总线/默认配置/阶段状态机/幂等守卫/持久化 restore/`createAutomationOrchestrator(adapters, config)`），不 import UI/路由/DOM/具体测试实现。
- **适配层**：`useAppStore.ts` 的 `getOrchestrator()` 模块级单例懒创建，**动态 import 组装真实适配器**（persistSnapshot/beginRun/evaluateOnBackend+evaluateAll+persistRun/generateReport/downloadUrl/listBridgeDevices/autoApproveConfirmation）注入编排器，避免与 features 循环依赖。
- **展示层**：TopBar(智能测试按钮+FlowStepper 阶段状态) / FlowScreen(左栏收起) / ResourcePanel(AutomationOverlay 大屏) / AgentChat+AssistantPanel(意图识别) 只订阅 store。

### 7 阶段状态机（route 映射 FLOWS 路径）
init-params(/init)→check-env(/run)→load-cases(/requirements)→run-cases(/run)→collect-result(/run)→gen-report(/report)→download-report(/report)。
run 状态：idle/running/completed/failed/stopped；阶段：pending/current/running/success/failed/skipped。

### ⚠️ 真机自动启动（无 PIN 自动授权，真做）
- 桥 `config.py` 新增 `AUTOMATION_TOKEN`（BRIDGE_AUTOMATION_TOKEN 环境变量，缺省空=关闭）。
- 桥 `bridge.py` 新增 `POST /confirmations/{token}/auto-approve`：校验 x-automation-token，`approve_channel="automation"`（区别于 human_pin），留痕可审计。CORS allow_headers 加 x-automation-token。
- 前端 `bridge.ts` 新增 `autoApproveConfirmation`；runCases 三段式：调 start 拿 pending → auto-approve → 带 token 重调 start 真 free-run。**未配 token/桥不可达 → 如实抛错，绝不静默降级成「电机已转」**。
- 红线不废：自动放行是独立 token 保护的第二通道，与人工 PIN 并行、互不削弱；token 与 APPROVER_PIN 同级秘密、不进浏览器包。

### ⚠️⚠️ 关键坑（永久）
1. **store 的 automationRunStatus 必须由事件订阅 sync 写回**——首版 `_syncAutomation` 漏写 runStatus，UI 类不生效，build/tsc 都抓不出，只有浏览器验收才抓到。
2. **编排器纯逻辑层不能用 useNavigate hook**：注入 `router.navigate`（import '../router' 全局实例，注意 store 在 src/state 下相对路径是 '../router' 不是 '../../router'）。
3. **失败太快**：本机无桥时 check-env 立即失败，`.automation-running` 窗口极短，浏览器验收须轮询抓 running 瞬间，不能固定延迟。
4. 动态 import 组装适配器的字面量对象**必须显式标 `AutomationAdapters` 类型**，否则 `onProgress` 等回调参数被 tsc -b 判成隐式 any（tsc --noEmit 不报、build 才报）。

### 验证（真跑）
- tsc 零输出；build built in 789ms；桥 py_compile 通过。
- 浏览器 `web/scripts/_verify_automation.mjs` **10/10 PASS**：按钮存在 / running 期间根容器+大屏浮层出现 / 无桥时 check-env 如实 failed（阶段条 check-env:failed、播报含失败）/ 失败不残留 / 可重试 / 可终止。
