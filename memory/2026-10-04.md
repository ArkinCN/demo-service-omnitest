### 根因（模型照抄我们喂的内容）
助手回答的英文全部来自**上下文摘要**（`agent_context.py` 的 `build_context_summary`）三处直接输出英文键：

2. ④「已勾选的候选改动」：`sel_cand.keys` 是英文参数键数组。
3. ⑥「最近一轮未采集到的实测量」（missing_measures）：前端 `loadLatestRun` 只给英文变量名，无中文映射。
4. **附带真 bug**：⑥ `failed_items` 是 BackendVerdict 对象数组，`_fmt_list` 对 dict 逐个 `str()` → 模型收到 Python dict 原文。

### 改动（前端 2 + 后端 1）

### ⚠️ 口径与教训（永久）
1. **「中文名(英文键)」是设计口径不是缺陷**：`_fmt_fields`/legend 输出统一为「中文名(键)」，配合 system prompt `_CITE_RULE` 的「正文只取中文名，括号里的编码删掉」形成闭环——模型拿到中文名后才可能输出中文；**禁止裸英文键（无中文包裹）**。写断言时别把括号里的英文键当缺陷（首版断言写错抓了个假 FAIL）。

3. `_fmt_list` 对 dict 会 `str()` 成 Python repr——任何传对象数组的字段都要先取中文名再进摘要。
4. missing_measures 的中文名来源 = 场景包 `requirements.runtime_measures[name]`（与 evaluate.ts 的 legend 同源），ActionDock 现算传入。

## ✅ 助手三条规范落地：中文化/表格渲染/跨页隔离（2026-10-04 第二轮，19+8 全 PASS）

用户提三条规范（附两张截图）：①界面与回复全简体中文、**不得裸输出 Markdown 格式**；②**跨页数据隔离**（流程5 问答不得答出流程1 参数）；③回复异常（格式错乱/语言混杂）修复。

### 截图问题定位（三根因）
1. **GFM 表格裸奔**：模型回答用 Markdown 表格列参数/判定，但 `Markdown.tsx` 只支持标题/粗体/列表/行内代码/分隔线，**不识别表格** → `|---|---|` 与竖线原样裸奔在气泡里（截图 1/2 的乱码正文）。
2. **英文流程 id + 英文参数键**：「已确认的流程：[init [已勾选]]」——摘要输出英文流程 id；6 个英文参数键是流程4 采纳的候选（模型重排表格只取键）。
3. **跨页泄露**：envelope 的 `zoneB.missing`/`placeholders` 全部来自**流程1 的本体属性**（context.ts 的 attrs），任何流程都带给模型 → 流程5 助手答出「预定位强度」等第一阶段参数。

### 改动（前端 3 + 后端 2）

| `web/src/features/agent-chat/agent-chat.css` | `.ac-md__table` 样式（淡边框/表头浅底/允许换行） |
| `backend/app/services/agent_context.py` | ① 新增 `FLOW_CN` 映射（对齐 data/flows.ts 五流程），「当前流程/已确认的流程」输出中文名；② **跨页隔离**：`missing`/`placeholders` 只在 `flow_id=='init'` 输出（用户口径：数据可流通，回答只关联当前页面） |
| `backend/app/services/agent_chat_service.py` | 新增 `_FORMAT_RULE`（输出格式与用语纪律）：①简体中文、禁「模型/AI」术语腔；②先结论后分点、表格用规范 GFM 语法（每行 `|` 开头结尾）、**禁把普通文字塞代码块**；③流程/参数一律中文名（禁 init/req 代号、括号英文键不进正文）；④回答只围绕当前页面。挂进 `_build_system_prompt` 两个分支 |

### ⚠️ 教训（永久）
1. **模型格式错乱先查前端渲染器支持面**：自写轻量 Markdown 渲染器是项目纪律（不引库），但语法支持面要跟上模型实际输出——模型爱用 GFM 表格，渲染器不支持就裸奔。加表格解析比让模型改用别的格式更稳（两条腿：前端支持 + system prompt 明确语法）。

## ✅ 跨页隔离前端层根治（2026-10-04 第四轮）

- 隔离不能一刀切：`report_header_missing` 是给 report 流程的本页等价物（第三轮已补），init 流程的 missing/placeholders 保留——每个流程只带「自己的本页数据」。
